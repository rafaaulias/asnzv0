# Anti-Snooze — Development Docs

Dokumentasi progres pengerjaan, dimulai 19 September 2026.

## Format

Setiap sesi pengerjaan menghasilkan satu file `YYYY-MM-DD-<topik>.md` berisi:

- **Context** — kondisi project saat sesi dimulai.
- **Permintaan** — apa yang diminta user.
- **Yang Dikerjakan** — perubahan konkret (file, alasan teknis).
- **Ekspektasi Hasil** — perilaku yang diharapkan setelah perubahan.
- **Yang Belum Sesuai Ekspektasi** — diisi pada sesi berikutnya jika ada temuan.
